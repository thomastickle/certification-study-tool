# Nest infrastructure review

This inventory covers the app-owned transport, lifecycle and development code added
by the conversion. Domain repositories, SQL and algorithms are outside this budget.
The goal is ordinary Nest feature code, with small exceptions where the established
security or compatibility contract needs more than standard framework defaults.

| Component                                                                              | Disposition and evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `application.module.ts`, feature/auth/health modules                                   | Keep standard Nest registration. Controllers/providers remain beside their owning modules; no second authentication acquisition. `compiled/application.spec.ts`, `runtime.spec.ts`.                                                                                                                                                                                                                                                                                               |
| `main.ts`, `production-application.ts`                                                 | Keep bootstrap/composition only. Production/static/OIDC tests exercise the compiled entrypoint graph.                                                                                                                                                                                                                                                                                                                                                                             |
| `runtime/runtime.module.ts`, `runtime-startup.ts`, `application-runtime.ts`            | Keep acquired-resource ownership exception: asynchronous provider failure can occur before Nest returns an app. Startup and post-create injection tests prove complete unwind and subsequent acquisition.                                                                                                                                                                                                                                                                         |
| `runtime/runtime-configuration.ts`, `study-library-scope.ts`                           | Keep explicit configuration and verified actor-owned SQLite lifetime. `runtime.spec.ts`, `security.spec.ts`, `production-lifetime.spec.ts`.                                                                                                                                                                                                                                                                                                                                       |
| `runtime/application-lifecycle.ts` (composed by `application.ts`)                      | Keep bounded public compatibility adapter for serialized init/listen/close and failed-startup cleanup. Replacing it with a new owner API would change every operator/test/benchmark caller. `review-lifecycle.spec.ts` checks fluent configuration, init, listen's HTTP-server result, HTTP adapter and provider identity; existing startup/close races remain covered. Global pipes are restricted only when joined-input endpoints are composed.                                |
| `security/security-express-adapter.ts`                                                 | Keep original-target admission before Express normalization. Ordinary middleware cannot recover the lost target afterward. `security.spec.ts`, `transport.spec.ts` cover encoded paths, unknown APIs, authority and implicit methods.                                                                                                                                                                                                                                             |
| `security/security.guard.ts`, `security-context.ts`                                    | Use standard Nest metadata/guard authorization. OriginalPath checks precede LibraryWrite policy; shared/private route owners declare static visibility. No duplicate regex authorization guard. `library-http.spec.ts` covers all role/namespace/error-order cases.                                                                                                                                                                                                               |
| `library-http/library-route.guard.ts`, monolithic library/study controllers            | Deleted. Resource controllers replace the dispatch-shaped controller organization; shared operations inherit into explicit namespace/policy owners. Existing HTTP matrices exercise discovery and inherited inputs.                                                                                                                                                                                                                                                               |
| `security/security.filter.ts`                                                          | Keep exact response-contract adapter: domain validation, workspace-changed and sanitized unexpected errors differ from Nest's default schema. Native BadRequestException validation now uses the same domain envelope. `request-failures.spec.ts`, `security.spec.ts`, `review-lifecycle.spec.ts`.                                                                                                                                                                                |
| `security/study-context.interceptor.ts`, `security-lifetime.ts`, `study-input-work.ts` | Keep joined ownership of personal storage, admitted requests and cancellation. A normal writableFinished close is successful; premature close cancels. Real manual-response regression and existing disconnect/shutdown tests prove the distinction.                                                                                                                                                                                                                              |
| `security/json-body.interceptor.ts`                                                    | Replace default async parameter parsing with one awaited route interceptor and normal Nest Body/pipe extraction. Preserve auth-before-body and scope-before-I/O. `review-lifecycle.spec.ts`, `security.spec.ts`, library/study HTTP matrices.                                                                                                                                                                                                                                     |
| `security/study-input-registration.ts`                                                 | Keep isolated opt-in compatibility adapter, not a feature requirement. Only JoinedStudyInputs endpoints rewrite Nest metadata. Existing adversarial async/sibling/inherited-pipe tests explicitly opt in; run them on every Nest upgrade. Ordinary endpoints accept normal body and validation pipes.                                                                                                                                                                             |
| `study-http/earned-body.ts`                                                            | Deleted. ExpireEarnedInterceptor makes expiry-before-body ordering explicit inside the verified personal scope.                                                                                                                                                                                                                                                                                                                                                                   |
| `http/json-object-body.ts` unowned iterator                                            | Deleted. Every supported reader supplies cancellation; one size-limited object parser remains. Invalid/media/oversize and unfinished-body shutdown tests retain coverage.                                                                                                                                                                                                                                                                                                         |
| `http/errors.ts`, `local-request.ts`, `request-url.ts`, `routed-http-handler.ts`       | Keep pure helpers and contracts, free of Nest decorators. Existing native helpers, admission and CLI graphs retain their contracts.                                                                                                                                                                                                                                                                                                                                               |
| `web/public-web.ts`                                                                    | Keep public serving ownership behind original-target admission; request/response work must drain before roots. `public-web.spec.ts`, `production-http.spec.ts`, `production-lifetime.spec.ts`.                                                                                                                                                                                                                                                                                    |
| `web/web-handler.ts`                                                                   | Retain the small exact-contract static resolver. A configured Express static + SPA fallback prototype still changed JS charset/cache headers, unknown-extension MIME, directory 404, missing-file-with-extension 404 and POST 405. Standard static serving is viable only with explicit parity adapters, not a drop-in deletion. `web-handler.test.ts` and production static tests specify the required behavior. No serve-static dependency was installed.                       |
| `web/development-vite.ts`, `development-vite-graph.ts`                                 | Retain the tested exception, rather than replacing it with another unproven wrapper. Fresh minimal middlewareMode controls in `vite-watcher-disposal.spec.ts` demonstrate stock Vite/Chokidar reopening native watches from delayed ENOENT callbacks after close; Nest-owned disposal prevents it. `vite-lifecycle`, `vite-reload`, `vite-activation` also cover partial startup, failed reload and close. A server.proxy topology alone does not fix those Vite-owned resources. |
| `scripts/development.ts`                                                               | Keep serialized build/server generations and signal ownership. Delete redundant per-root-file watchers: one directory watch covers edits, replacement and missing-file gaps. Real supervisor tests verify deletion/recreation recovery, rapid edits, compiler serialization and no orphan children.                                                                                                                                                                               |
| `scripts/build-server.ts`, tsconfig.server                                             | Keep compiled decorator metadata/ESM emission and schema copy. Native TypeScript stripping alone cannot execute these Nest controllers. Full check and production tests validate the graph.                                                                                                                                                                                                                                                                                       |

Standard Nest [guards](https://docs.nestjs.com/guards) and
[interceptors](https://docs.nestjs.com/interceptors) now own the feature policy/body
path. The [static module](https://docs.nestjs.com/recipes/serve-static) and
[Vite server APIs](https://vite.dev/guide/api-javascript.html) were considered;
retained exceptions above identify concrete parity or disposal failures, rather
than claiming the standard frameworks cannot be used.

The static prototype and exact execution logs are retained locally with the PR
verification evidence. Source line counts and final executed tests are recorded in
the PR after the final diff, separately from test/docs/build changes. Historical
performance tables remain pinned to their original source; fresh smokes establish
correctness and reconstruction compatibility, not new timing claims.
